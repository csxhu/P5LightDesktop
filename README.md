# P5 轻桌面

面向小鹏 P5 车机的轻量桌面、应用快捷入口及语音适配项目。当前整理基线：**0.4.5 / versionCode 11 / com.local.p5home**。

这是从现有本地工程恢复的可构建源码快照：完整的 Smali、资源和 Manifest，加上可维护的热点 Java 源码及部分语音 Java 源码。**不是完整的原生 Java/Gradle 工程，不能直接按 Android Studio 项目编译。** 反编译 Java 仅用于阅读，实际构建以 `app/` 为准。

## 功能

- 轻量桌面、应用快捷入口和桌面管理。
- 默认导航选择、进入桌面自动打开导航；代码包含原车导航、高德和百度适配。
- 音乐路由与汽水音乐适配，包括手机版搜索桥接。
- 小 P / 自定义唤醒词、模型问答配置、语音输出相关模块。
- 顶部应用栏、自定义槽位、转向影像开关和车辆状态观察模块。
- 进入轻量桌面自动开启 Wi-Fi 热点的独立设置、手动热点开关、热点名称与密码显示。

功能存在于源码不等于所有车机/固件均已验证。详细历史、已验证范围和限制见 [版本记录](CHANGELOG.md)。

## 目录

| 路径 | 用途 |
| --- | --- |
| `app/smali/` | 主 DEX 的实际构建源码，含启动崩溃修复 |
| `app/smali_classes2/` | 第二 DEX 的语音/音乐桥接源码 |
| `app/res/`、`app/assets/` | 资源和 Xposed 入口 |
| `app/AndroidManifest.xml` | 应用组件、权限和版本 |
| `src/hotspot/` | 可独立编译为 Smali 的热点 Java 实现 |
| `src/voice/` | 本地保留的语音/音乐 Java 修改源码 |
| `reference-java/` | 反编译阅读材料，可能与最新 Smali 不完全同步 |
| `scripts/` | 相对路径构建、热点 Java 转 Smali 脚本 |
| `docs/` | 构建、架构、历史 APK 指纹、发布说明 |

## 开始修改

先阅读 [构建说明](docs/BUILD.md) 和 [开发指南](CONTRIBUTING.md)。构建无需原始 APK，也无需车机在线。设备功能依赖相应车机系统服务，热点控制需要 root；部分语音/顶部栏功能需要 LSPosed/Xposed 和相应作用域。

本目录不包含签名私钥、车机数据库、运行日志、截图、第三方车机 APK、SDK 或编译工具二进制。
